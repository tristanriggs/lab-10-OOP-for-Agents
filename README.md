# Gym Membership Assistant

This project is a mock gym membership assistant named Max. It helps customers check membership prices for basic and premium plans.

The assistant uses a separate tool class to look up membership prices. It also saves conversation history and responds to questions it cannot answer.

The membership prices are made-up examples and are not connected to a real gym. Requests to cancel, change, or refund memberships are directed to a staff member because the assistant cannot make those changes.

If this assistant used real customer data, incorrect information or privacy issues could cause problems. A real system would need secure customer records and accurate membership information.
